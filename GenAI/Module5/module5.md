# Module 5 - Final Project, Final Quiz, and Course Wrap-Up
---

## What to Expect

In the final module, you will consolidate your learning by completing a hands-on project that challenges you to apply generative AI to build a personalized learning platform for developers. This project consists of two parts, building the backend, using your choice of Java, Python or JavaScript programming languages and building the frontend using either bolt.new, a web-based tool, or bolt.diy, which you'll find hosted in a separate IBM lab instance.
